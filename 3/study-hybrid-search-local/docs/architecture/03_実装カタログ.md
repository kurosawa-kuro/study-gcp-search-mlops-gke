## 2. PostgreSQL テーブル

| テーブル | 役割 |
|---|---|
| `properties` | 物件マスタ |
| `embeddings` | multilingual-e5 embedding |
| `feature_mart_property_features_daily` | rerank 用特徴量 |
| `ranking_log` | `/search` の検索ログ |
| `feedback_events` | legacy 互換の feedback 記録 |
| `search_events` | 検索イベント |
| `search_impressions` | impression 単位の候補・rank・score |
| `user_actions` | 5 種 action |
| `ranking_labels` | labeling 結果 |

## 5. Make ターゲット

| Target | 動作 |
|---|---|
| `make build` | `build-jobs` + `build-api` |
| `make build-jobs` | shared pipeline image build |
| `make build-api` | search-api image build |
| `make up` | infra 起動 + `migrate-db` |
| `make migrate-db` | idempotent migration 再適用 |
| `make warm-model` | multilingual-e5 を `hf_cache` に事前取得 |
| `make seed` | property / embeddings / feature mart / Meilisearch / Redis 同義語投入 |
| `make train` | `ranking_labels` 実データで学習、空なら fallback |
| `make label` | `ranking_labels` 作成 |
| `make build-training-dataset` | `training_dataset.csv` 出力 |
| `make evaluate` | latest model の評価 |
| `make verify-contracts` | workflow contract 検証 |
| `make verify-app` | app / API / UI 総合検証 |
| `make verify-ml` | labeling / dataset / retrain / evaluate 総合検証 |
| `make verify-all` | 全体検証 |

## 6. 学習成果物

```text
ml/registry/artifacts/
├── latest -> <run_id>/
├── <run_id>/
│   ├── model.lgb
│   ├── metrics.json
│   └── feature_importance.csv
└── datasets/
    └── <run_id>/
        └── training_dataset.csv
```

補足:

- `training_dataset_job` は CSV 出力時に `label` 列を `relevance_label` に rename する
- `evaluation_job` は `metrics.json` に `evaluation_metrics` と top-level metrics を書く
