## 1. 何をもって OK とするか

Phase 3 の OK は、単に `/search` が 200 になることではない。最低限、次を満たすこと。

- lexical + semantic + rerank の 3 段検索が成立している
- `search_events` / `search_impressions` / `user_actions` / `ranking_labels` が動いている
- `/ui/dev/model/metrics` と `/ui/dev/data` が表示できる
- `make train` が `ranking_labels` 実データを読める
- `make verify-all` が通る

補足:

- trainer は実データ接続済み
- `pipeline.evaluation_job.main` の hold-out 評価はまだ synthetic split

## 4. 一過性エラーと recovery

| 症状 | 原因候補 | まずやること |
|---|---|---|
| `make up` で postgres timeout | 旧 volume / 旧 container | `docker compose down --volumes` → `make up` |
| 初回 `make seed` が遅い | Hugging Face model 未取得 | `make warm-model` |
| `/readyz` で `rerank_enabled=false` | model artifact 未生成 | `make train` |
| `/feedback` は通るが `ranking_labels` が増えない | `make label` 未実行 | `/feedback` 実行後に `make label` |
| `/ui/dev/data` に dataset が出ない | dataset 未生成 | `make build-training-dataset` |
| 同義語更新後も結果が古い | Redis cache HIT | `make seed-synonyms` と `search:*` key 削除 |
