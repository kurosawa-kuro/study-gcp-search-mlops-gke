## 2. 実装マップ

### 2.1 `app/`（search-api）

- `main.py`: FastAPI entrypoint
- `composition_root.py`: DI コンテナ構築
- `api/routers/`: `/api/v1` `/ops` `/ui` の handler
- `services/protocols/`: Port 定義
- `services/adapters/`: 外部接続 adapter（Elasticsearch / KServe / PubSub / BQ）
- `services/noop_adapters/`: フォールバック実装

### 2.2 `ml/`

- `data/`: feature 組み立て・repository
- `training/`: LightGBM 学習
- `serving/`: encoder/reranker 推論
- `evaluation/`: metrics/validator/report
- `registry/`: Vertex Model Registry adapter

### 2.3 `pipeline/`

- `data_job/`: embedding 系 pipeline + Dataform
- `training_job/`: reranker train pipeline
- `evaluation_job/`: offline 評価 pipeline
- `dags/`: Composer 3 DAG
- `workflow/`: compile/trigger 補助

### 2.4 `infra/terraform/`

主要 module:
- `iam`, `data`, `messaging`, `monitoring`, `vertex`, `slo`
- `vector_search`, `gke`, `kserve`, `composer`, `elasticsearch`

### 2.5 `infra/manifests/`

- `search-api/`: deployment/service/gateway/hpa/config
- `kserve/`: encoder/reranker InferenceService
- `elasticsearch/`: ECK CR + Kibana + Service + NetworkPolicy
- `policies/`: IAP / NetworkPolicy

### 2.6 `scripts/`

- `setup/`: deploy-all / destroy-all / seed 系
- `deploy/`: API / KServe deploy
- `ops/`: livez/search/components/accuracy/vertex 系検証
- `ci/`: sync/layer check
